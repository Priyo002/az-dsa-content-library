# Graph Terminologies image style reference

Authoring reference only; not part of the student lesson. Based on visual inspection of all seven existing images in `1_Graph_Terminologies_1.md`. Three inaccurate diagrams were subsequently replaced with corrected versions in the same style.

## Shared visual style

- Warm, pale ivory/cream background; flat, clean educational diagrams with generous empty space.
- Rounded rectangular outer border inset from the canvas. Most borders are dark brown/near-black; the opening graph uses muted teal. Stroke thickness varies slightly across the originals.
- Solid muted blue/teal circular vertices with strong black outlines and centered white numeric labels.
- Straight dark edges, with clear filled arrowheads for directed edges. Edge weights appear next to the edge, not inside the vertex.
- Friendly, legible handwritten/monospaced-looking lettering rather than a heavy display font. Dark brown/charcoal main text, muted red equations and counts, occasional teal/blue annotations.
- Simple side-by-side comparisons with matching graph layouts when demonstrating a change in one property.
- AlgoZenith logo in the upper-right, comfortably inside the border: navy-to-blue triangular A mark with white stylized Z and the blue AlgoZenith wordmark beneath. Reuse the supplied mark rather than inventing a substitute.
- No 3D effects, ornamental icons, shadows, or dense decorative elements. Preserve roomy margins and avoid edge crossings where possible.
- Canvas proportions vary; match the closest existing reference for the intended diagram rather than forcing every image to be square.

## Reusable prompt direction for a later image task

Use the actual reference image and logo as inputs; do not infer mathematical content from style alone.

## Content caution

Use the corrected local diagrams in `images/` for sparse/dense, paths/cycles, and SCCs. Sparse/dense is a qualitative comparison with no fixed midpoint. Paths have no repeated vertices; cycles repeat only the start at the end and do not reuse edges. Every circled SCC must have mutual directed reachability. Archived originals in `images/reference/` are style references only, not mathematical templates.
