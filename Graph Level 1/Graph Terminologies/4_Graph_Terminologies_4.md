# Graph Terminologies - 4

## Level-6 Terms

### Hamiltonian

#### Hamiltonian Path
A **Hamiltonian path** is a path in an undirected or directed graph that visits each vertex exactly once.

#### Hamiltonian Cycle
A **Hamiltonian cycle** is a Hamiltonian path that starts and ends at the same vertex, forming a cycle that visits each vertex exactly once (except for the starting/ending vertex).

#### Hamiltonian Graph
A **Hamiltonian graph** is a type of graph that contains a Hamiltonian cycle. The presence of such a cycle allows for a continuous loop that covers every vertex once without repetition.


### Eulerian

#### Eulerian Path
An **Eulerian path** in a graph is a path that uses each edge exactly once. This path does not need to return to the starting vertex.

#### Eulerian Cycle
An **Eulerian cycle** is an Eulerian path that starts and ends at the same vertex, using every edge exactly once and returning to the starting vertex.

#### Eulerian Graph
An **Eulerian graph** is a type of graph where there exists an Eulerian cycle. This means every vertex in the graph connects in a way that allows for a closed loop that covers every edge exactly once.
